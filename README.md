# WAYFIN — финансовый учёт малого бизнеса

Рабочий MVP для учёта доходов, расходов, счетов, клиентов, планов и денежных остатков.

## Что реализовано

- быстрый ввод доходов и расходов;
- оплаченные и запланированные операции;
- несколько касс, карт и банковских счетов;
- карточки клиентов с выручкой и ожидаемыми оплатами;
- дашборд с балансом, денежным результатом и графиками;
- план–факт по категориям;
- прогноз остатка после будущих платежей;
- экспорт операций в CSV и резервная копия JSON;
- адаптация для iPhone и компьютера;
- постоянное хранение данных в Cloudflare D1.

## Технологии

- React 19 и TypeScript;
- Vinext / Vite;
- Tailwind CSS;
- Drizzle ORM;
- Cloudflare D1;
- Recharts.

## Основные папки

- `app/` — интерфейс и API;
- `db/` — структура базы данных;
- `drizzle/` — миграция для создания таблиц;
- `components/ui/` — компоненты интерфейса;
- `public/` — иконка приложения.

## Запуск для разработки

Требуется Node.js 22 или новее.

```bash
pnpm install
pnpm build
pnpm dev
```

Для базы данных используется привязка `DB`, указанная в `.openai/hosting.json`. При публикации через ChatGPT Sites миграция из папки `drizzle/` применяется автоматически.

## Как загрузить в новый GitHub-репозиторий

```bash
git init
git add .
git commit -m "Initial WAYFIN MVP"
git branch -M main
git remote add origin https://github.com/waystudia/WAYFIN.git
git push -u origin main
```

Если репозиторий создаётся с телефона, проще создать на GitHub пустой `WAYFIN`, подключить приложение GitHub к ChatGPT и попросить ChatGPT загрузить этот проект.
